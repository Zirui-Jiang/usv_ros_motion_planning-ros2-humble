# 艇端三个业务模块与感知地图所有权

用户已确认：感知定位、决策规划、航行控制均部署在艇端；岸端只下发任务和监控；地图由感知模块维护。路径规划与轨迹规划共同属于决策规划模块，内部可以保留对象传递。未来存在不同计算机部署的需求，但首版只要求同机独立运行和联调，不要求跨机器验证（Q9）。

本轮转换仅覆盖普通单目标导航。定点值守、阵位保持及其专属保持、制动、逃逸控制不纳入改造；其现有文件不因此删除。此记录确认用户已经给出的模块边界，具体消息协议仍待澄清；碰撞检查位置另见 [ADR 0002](0002-collision-check-placement.md)。

当前使用 ROS 2 开发，未来需对接甲方 DDS；甲方协议尚未知。原生 DDS 直连、SDK 适配或网关的选择均保留为后续接口对接决策，不假定 ROS 2 消息可直接互通。

- Q10：当前实际船体占用检查保留在航控的控制周期内；轨迹碰撞检查留在决策规划侧。
