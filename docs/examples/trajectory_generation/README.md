# LOS 轨迹生成说明示例

本例手工指定几何路径 `(0,0) → (8,0) → (8,12)` 和初始状态（艏向正东、纵向速度 0.2 m/s），调用当前 `LosTrajectoryPlanner.plan()` 生成一次参考轨迹。参数读取原工程的 Otter dynamics 与 LOS YAML。本例没有运行 A*、障碍地图校验、闭环控制或实船试验；所有表格和曲线均为程序生成的期望参考，输入状态也不是实测数据。

在原仓库根目录运行：

```powershell
python -B docs/examples/trajectory_generation/generate.py
```

需要 NumPy、PyYAML 和 Matplotlib。结果为 [参考轨迹图](trajectory_generation.png)、[完整八列数据](trajectory.csv)、[输入参数和源码哈希](example.json)。脚本保留当前算法逻辑，不修改控制器和规划器源码。

> 2026-10 说明：这里保存的图、CSV 和 JSON 是用当时的配置生成的（轨迹时域 20 s、巡航速度 1 m/s）。现在的共享配置是时域 10 s、巡航速度 2 m/s，重新运行脚本会得到 21 个点并覆盖这三个文件；图标题里的“20 s 时域”和速度轴上限 1.12 写死在脚本里，重新生成前需要先改。下文的数字描述的是已保存的那一版输出。

轨迹的 41 个点覆盖 0–20 s，每 0.5 s 一个点。第 20 s 的参考位置尚未到最终目标；这体现单轮局部时域，不是“20 s 内必然完成整个任务”。实际系统按新状态滚动生成后续参考。

图中参考初始速度为 1 m/s，手工设定的实际状态输入 u 为 0.2 m/s；两者不同是现有 LOS 的参考速度初始化行为。当前速度按剩余距离比值给出，路径段切换也会改变该距离估计。因此曲线存在折变，不能据此宣称已经满足实船加速度、加加速度或动力学约束。

图中的弯曲参考偏离折线路径；完整系统必须再检查参考的船体扫掠范围。几何路径无碰撞不能自动保证生成的转弯参考无碰撞，本例没有设置障碍。
