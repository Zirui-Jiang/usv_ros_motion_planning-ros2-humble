# Hybrid 全局路径复用与局部轨迹更新

## 用户要求与实现范围

用户明确要求先裁剪路径、在可直连时去掉冗余节点，并降低全局航路更新频率。
采用事件触发的全局搜索：首次目标、剩余路段失效、路径与目标不匹配、跟踪偏差过大时搜索。
正常5 Hz周期复检并裁剪已有全局几何，使用最新实测状态重新生成LOS局部轨迹。

## 几何与安全约定

- 全局路径不是实测轨迹：小跟踪偏差交给局部轨迹处理，不能每次将实测位置/艏向硬接成全局折线。
- 已走前缀沿原直线或圆弧的精确投影裁剪，保留目标位置和朝向。
- 限制进度匹配在剩余路径前10 m，防止闭合或交叉路线跳到远处后缀。
- 默认位置偏差上限2 m、朝向偏差上限60°；超过门限重新全局搜索。
- 剩余路径按当前地图重新验证中心代价和船体，不只看两个节点。
- 新路径的直线快捷连接必须前进方向、两端切线朝向一致且完整直线无障碍；保留有转角的圆弧和所有必经点。
- 5 Hz局部参考继续携带当前state.stamp，独立做预测船体检查；不刷新旧轨迹时间戳。
- ROS全局path在裁剪结果变化时随已验收的局部周期立即发布，相同路径去重；显示更新不触发全局搜索；失效/取消时清空一次。
- 实测航点进度进入下一阶段时，清除已完成阶段缓存一次；新阶段重新规划后恢复正常复用。
