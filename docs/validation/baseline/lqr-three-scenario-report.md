## 结果含义

直航的直接停机语义已在先前记录中确认：旧控制器仅按进入目标距离范围锁存到达，清零前速度仍约 2.00 m/s；仿真状态机随后进入 PENDING，不再更新规划和控制。惯性运动使艇漂出目标范围。详见 ../baseline-matrix-002/cpp_lqr_straight_01/lqr-stop-diagnosis.md。

转弯在仍有非零推力时超过预先设置的最大横偏阈值，故不能归为没有运行或只有停机缺陷。没有继续跑到最终到达，因此不推断后续是否可能重新收敛。

圆柱场景以 2.2×1.2 m 矩形作为艇体代理。暂停样本的保守扫掠间隙为 -0.250142 m；同一瞬时位姿的矩形—圆间隙为 -0.221835 m。负值表示此几何代理已发生重叠；本次未记录 Gazebo 接触传感器事件，不据此宣称已证实物理碰撞。

这些是原基线在固定参数下的真实不满足判据观察，不应作为正确 LQR 输出的判等目标。报告不把三条诊断样本合成为完整 18 组成功率，也不推断尚未运行的其他重复例。

## 进程退出与证据

三个样本的原 sim_env_node 收尾均为 -6，属于独立退出健康缺陷；没有为使对照好看而修改旧代码。此次新运行的两个 harness 都由监督器向自身 PID 发送 SIGINT 并完成清理；cleanup-check.json 记录无残留进程。

report.json 保存参数回读、消息数量、完整暂停样本和原始日志 SHA256；每例目录保存 events.jsonl、launch.log、summary.json，相邻 supervision 目录保存完整命令、冻结脚本 SHA256 与 pause.json。两个新例的输出与之前直航相互独立，未覆盖任何旧结果。
