# 障碍阈值校准：捕获输入离线诊断

这份诊断支持把项目导航配置的 `obstacle_factor` 从 0.5 校准为 0.25，作为**重新初始化后的独立闭环候选**。它没有验证实际艇体的惯性停止过程，也没有把未通过的格内绕障用例改判通过。搜索算法、邻域、启发式和阈值公式 `254 * obstacle_factor` 均保持不变。

原始数值、完整路径与八列 LOS 轨迹、输入文件 SHA-256、捕获参数和算法源码哈希见 [obstacle-factor-calibration.json](obstacle-factor-calibration.json)。输入来自 `/home/usv/usv_migration/results/python-grid-interior-001/python_pid_single_obstacle_02`。该试验的 PID 预瞄为 2.6 s，LOS 前视距离为 1 m、航点切换距离为 5 m、参考角速度上限为 0.3 rad/s；圆柱为 `(29.125, -10.125, r=1)`，验收艇体矩形为 2.2 m × 1.2 m，安全裕度仍为 0.2 m。

## 输入和方法

使用三个已捕获的地图与状态快照，分别独立执行当前真实 Python A* 与 LOS 实现。配置来自该用例记录的有效参数；记录中没有 `planner_name`，按原启动默认明确取 `astar`，其余默认补入项列在 JSON 的 `defaulted_keys`。搜索结束后，把最后一个栅格中心替换为精确目标，随后生成理想 LOS 参考并检查其艇体扫掠。

| 快照 | 状态时间 / s | 地图时间 / s | 起点原始代价 | 输入后缀 |
|---|---:|---:|---:|---|
| 初始目标 | 4.5 | 4.5 | 0 | `90d3c223` |
| 首次参考失效 | 11.4 | 10.5 | 41 | `fbb90af0` |
| 中途阻塞 | 13.5 | 13.4 | 75 | `304030b9` |

地图、状态和上下文分别来自最新订阅回调，并非原工作进程同一次请求的原子输入。因此，离线重新规划状态与现场日志可能不同；这类差异不能直接证明原工作进程输出有误。各输入文件的路径及 SHA-256 保存在 JSON 对应快照中，事件文件哈希为 `aba5a33a2a843ae9376d4a847d4c7c2743838dc2137a6daa309e01ff36a4743b`。

在初始图上，0.25 相比 0.5 增加约 0.217 m 的中心路径距离和 0.262 m 的理想参考扫掠下界。0.25 与 0.2 在两个搜索成功的捕获图上得到完全相同的离散路径和 LOS 数组，因而这组输入没有继续降至 0.2 的额外离散收益；该结论不推广到其他地图。

在中途 raw cost 为 75 的起点，收紧到 63.5 会触发当前 Python 的严格阻塞端点契约，直接 `NO_PATH`。原 C++ A* 的软膨胀区行为有所不同：当邻居超过阈值且不低于当前格代价时才拒绝，允许沿严格下降的软代价逐格逃离。Python 的严格端点判断是迁移引入的语义变化。若独立闭环候选确实因此死锁，应单独验证恢复这项原行为，并同步审核路径段检查；任何恢复仍须拒绝地图外、254 lethal 和 255 unknown，不能把离线结果当成允许穿越真实障碍的依据。本诊断没有修改该行为。

## 为什么仍需要真实闭环复验

LOS 轨迹按参考速度和参考角速度积分，不传播实测 `u/v/r` 或 PID 推力引起的真实响应。当前参考扫掠检查与控制周期的当前艇体检查，都不能单独证明未来零推力滑行段安全。该现场的实际角速度最高约 0.929 rad/s，明显超过参考角速度上限 0.3 rad/s。

真实记录的 14.5–17.6 s 区间有 31 个状态样本、83 条推进器消息，观察到的推进器消息全为零，但艇体中心仍移动 1.004978 m、航向变化 0.447120 rad，速度从 0.680741 降至 0.133419 m/s。末端仍未静止，所以该数值只是观测到的部分滑行距离，不能称为完整停止距离。

独立几何复核得到：实际观测位姿矩形到圆柱的最小距离约 +0.029637 m；按最短角插值并进一步细分，扫掠下界约 +0.029587 m。此前粗分段下界 −0.006092 m 包含保守余量，并不证明已观测到艇体相交。该用例仍明确不满足 0.2 m 裕度，不改变失败记录。详细几何文件位于 `scripts/validation/diagnostics/grid_interior_circle02/`。

后续候选必须从一致初始状态独立运行，保留原安全裕度、每次重复、失败快照及性能证据；候选是否避免近界转弯、是否触发软代价起点阻塞，均由真实闭环结果回答。这份离线诊断不报告构建、性能或闭环验收通过。
