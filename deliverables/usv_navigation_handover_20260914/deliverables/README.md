# 交付物适用范围

当前需求是梳理规划层与可替换 `controller` 控制层之间的接口。航控指该控制层，不是另一个下位机模块。当前设计依据为 [规划层与航控接口](../docs/planning-control-interface.md)。

`control_workspace/` 和 `control_workspace.zip` 是上一轮已生成的数值开发快照。算法提取与相应数值验证记录仍可用于了解原代码，但归档内的旧航控接口文档采用了下位机边界，不适用于当前需求。快照及其哈希保留原样，不将它们称为已经完成的规划—控制解耦或换艇适配。

当前接口设计稿未修改原工程运行时，也未新增航控模块。
