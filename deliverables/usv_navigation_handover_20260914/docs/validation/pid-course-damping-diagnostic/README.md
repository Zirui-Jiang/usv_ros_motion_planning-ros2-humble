# PID 航向微分项的有界离线诊断

现有数据为仅改变现有 `k_d_course: 0→0.10` 的小规模试验提供了**阻尼方向上的依据**，但不足以证明能修复正式 RMSE 超限。正式和同版本候选的中段都存在比 CPP 更强的偏航回摆；在重构参考下，Kd=0.10 大多数时候会反向作用于角速度。另一方面，参考切换、首拍误差微分、限幅和 `wrap_angle(yaw)` 使它不是单纯的 `-Kd*r` 阻尼，实际控制输入记录也不足以精确恢复全部推力。

本目录只读取既有三份转弯 01 记录，没有修改配置、算法或启动 Gazebo，也没有改变正式结论。正式源 RMSE 比值仍为 1.1091297178；候选通过不能替换正式编号。

## 符号与局部模型

当前 [PID 实现](../../../src/core/controller/controller/controller/pid_controller.py) 采用

\[
e_k=\operatorname{wrap}(\theta_{ref,k}-\psi_k),\quad
Y_k=\operatorname{wrap}\left(2e_k+K_d\frac{\operatorname{wrap}(e_k-e_{k-1})}{dt_k}\right),
\]

\[
L_k=\tfrac12(S_k-Y_k/D),\quad R_k=\tfrac12(S_k+Y_k/D),\quad D=0.395.
\]

`Y` 是控制分配前的归一化航向作用量，不直接以 N·m 计。实际左右桨横向位置为 `+0.395/-0.395 m`，与控制 D 一致，见 [艇体 xacro](../../../src/sim_env/urdf/otter/otter_base.urdf.xacro) 第 65/71 行；[推进器配置](../../../src/sim_env/urdf/otter/thrusters/otter_gazebo_thruster_config.xacro) 为线性映射、命令 ±1、力 ±50 N。水平且未饱和时，`τz=50D(R-L)=50Y`：正 Y 提高右桨、降低左桨，产生正偏航。

参考航向固定时，误差微分约为 `-r`，故正 Kd 的符号提供阻尼。采用 YAML `Iz=10.03` 和插件 `Ndotr=1、nR=20、nRR=0`，固定参考、小角、未饱和的简化模型为

\[
(10.03+1)\ddot e +(20+50K_d)\dot e+50K_p e=0.
\]

`Kp=2` 下，Kd=0/.10 的模型阻尼比分别约 **0.3011/0.3764**。这只表明该局部模型增加了阻尼，未通过实测拟合真实阻尼比；模型忽略移动预瞄参考、侧滑、滚转、附体惯性、饱和、采样和时序。相关插件参数见 [动力学 xacro](../../../src/sim_env/urdf/otter/dynamics/otter_gazebo_dynamics_plugin.xacro)。

## 实测相位与条件输出

以下中段定义仍为沿程 3–9 m。航向误差来自已接收轨迹重构，角速度来自源 odom，差动来自最近完整收到的三轴命令（轴接收相差不超过 0.01 s，命令年龄不超过 0.2 s）。

| 中段观测 | 正式 Python | 候选 Python | CPP |
|---|---:|---:|---:|
| 重构航向误差 RMS / rad | 0.13207 | 0.13507 | 0.03837 |
| 实测角速度 RMS / rad·s⁻¹ | 0.31750 | 0.32787 | 0.10194 |
| 已收右减左差动 RMS | 0.69741 | 0.71598 | 0.20605 |
| Kd=.10 的 D 作用量 RMS | 0.03994 | 0.04094 | 0.01277 |
| `|r|>0.1` 时 D 与 r 反号 / 总数 | 71 / 73 | 71 / 75 | 22 / 22 |

正式中段航向范围约 `[-1.7884,-1.3657] rad`，候选 `[-1.8053,-1.3566]`，CPP `[-1.6463,-1.4632]`。Python 的回摆幅度及角速度较大，符合阻尼不足的部分表现，但移动参考下不能仅由此唯一辨识欠阻尼。特别是候选的角速度 RMS 还略高于正式，而候选 RMSE 明显更低，说明“回摆幅度”本身不能解释两次全部横偏差异。

在正式前段，D 与显著角速度反号为 42/46，候选为 39/45；存在同号观测，不能将 D 一概说成阻尼。例如参考变化时 `d(e)/dt=d(theta_ref)/dt-r`，参考导数可能抵消或超过 `-r`。LOS 每次以当前姿态更新预测参考，在角速饱和区还可能使参考航向随实际航向一起转动。

两个正式中段检查点说明阻尼方向：

| 源时刻 / s | 实测 r | 重构 e | P=2e | D(.10) | 条件解释 |
|---|---:|---:|---:|---:|---|
| 9.1 | -0.62117 | +0.000651 | +0.001302 | +0.094378 | 误差接近零仍顺时针转动，D 给反向作用 |
| 10.1 | +0.54705 | +0.004369 | +0.008739 | -0.077198 | 回摆至逆时针转动，D 再次反向 |

两个点都正逢已收到参考更新，不能证明实际控制当拍使用了这里重构的同一参考。

完整未限幅 surge 在观测桨饱和时无法恢复，故脚本将该处的全桨输出留空。仅在已收左右命令均未饱和时，将它们的和作为相同的 surge 代理，分别代入 Kd0/.10 的航向量，再分别裁剪到 [-1,1]。正式中段这类条件输出最大单桨变化约 **0.12155**；9.1 s 的代理下，左右输出从约 `[0.16171,0.16500]` 变为 `[0.04224,0.28447]`，两者均未触及限幅。

此代理具有明显不确定性：正式中段 Kd0 重构 Y 与已收差动反推 Y 的残差 RMS 为 **0.06871**，大于 D 作用量 RMS **0.03994**；候选为 0.07253。原因不能只归为数值误差，异步引用和未记录的速度控制输入足以造成差异。因此这些全桨数字仅用于量级和方向，不可声称是原 PID 的精确反事实输出。

## yaw 包络、首拍与参考切换

必须先检查未包络的 `2e+Kd*Δe/dt`，再讨论 `wrap_angle(yaw)`，因为跨 ±π 后可能翻转符号。本次条件重放结果：

| 记录 | Kd0 最大绝对未包络 Y | Kd.10 最大绝对未包络 Y | 跨 ±π 次数 |
|---|---:|---:|---:|
| 正式 | 1.618953 | 2.428429 | 0 / 0 |
| 候选 | 1.604190 | 2.406285 | 0 / 0 |
| CPP | 1.501334 | 2.252001 | 0 / 0 |

最大 Kd.10 值来自模拟首个可用观测：正式 e=-0.80948、last_e=0、dt=.1，微分项为 -0.80948，Y=-2.42843。它是参考初始化冲击，同实测 r=-0.05879 下的纯阻尼 `-Kd*r=+0.00588` 方向相反；实际观察到的左右桨已是 `[1,-1]` 饱和，不能由 raw 差动变化推断首拍增加实际转矩。

实际控制逐拍 dt 未记录。本次约 .1 s 源间隔无翻转，不代表任意正 dt 都安全。对同样初误差和 last_e=0，避免包络翻转需要 `dt>0.05316 s`；若 dt=.05，则未包络 Y 约 -3.23791，经 wrap 变为正值。通用检查条件是

\[
\left|2e+0.10\,\operatorname{wrap}(\Delta e)/dt\right|<\pi.
\]

这是代码允许小正 dt 时的可构造边界，**本次日志没有证明发生过这种翻转**。首拍以外，正式前段 D 作用量最大 0.26234；中段最大 0.09602。中段参考更新时 D RMS=0.04680，保持同一参考时=0.03161，说明参考更新和微分值放大同时出现，但不等于已经隔离出传感噪声。

当前微分没有低通滤波。在 dt=.1 s 时，单次参考跳变 .03 rad 会额外产生 .03 的 Y，在未限幅分配下对应每桨约 .038 的相反变化；这只是敏感度计算，不能虚构为实测噪声标准差。航向噪声、参考切换和时间间隔缩短都会放大该项。现有数据不足以分离三者各自贡献。

## 结论和最小试验边界

仅调现有 Kd_course=.10 的试验有符号、局部模型和观测方向依据，适合作为受限候选；它尚不是可宣布修复的配置。若开展试验，应继续保持相同预瞄、其他增益、场景、编号和主度量，额外记录实际控制 dt、e、Δe、包络前后 Y 及裁剪前后推力，尤其覆盖首次非零、恢复和参考更新。先检查上述包络翻转、过量差动和噪声，再评价实际 RMSE/到达时间，不能以开环反号比例代替闭环验收。

本诊断没有建议同时改变预瞄或增加滤波/新控制方法，也没有把原正式失败改判。
