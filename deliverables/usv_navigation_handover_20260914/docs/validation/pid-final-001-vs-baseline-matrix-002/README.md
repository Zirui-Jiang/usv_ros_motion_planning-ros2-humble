两例均覆盖试验首尾，有持续积分、计数守恒，观测区间没有 overflow 或 expired 增长。其 queue_ms 是已经完成积分扫描的等待时间分布：第一例各报告 P95 为 84.94–103.45 ms，报告最大值最高 140.65 ms；第二例 P95 为 84.90–92.33 ms，报告最大值最高 108.90 ms。这些证据与稳定的单帧 TF 流水等待相容，不能据此称为持续积压失败。现有比较器要求净增时必须看到回落，因此本次仍保持 unknown，不在事后更改判定。

后续正式运行之前，应固定更直接的积压定义和量测：服务欠账是否持续增长、满容量占时、最老 pending 的墙钟年龄及身份轮换、queue_ms 分位数/最大值、采样间隔覆盖、overflow/expired 与处理增量。仅在 drain 后观察剩余队列会遗漏剔除前的过期年龄和瞬时峰值，必须标清采样阶段，不能把这些量当作连续时域的真实峰值。
