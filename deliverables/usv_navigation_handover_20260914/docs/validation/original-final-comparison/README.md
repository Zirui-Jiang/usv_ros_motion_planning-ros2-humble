`python_pid_turn_03` 的控制和扫描耗时均通过。积压 unknown 的直接来源是 `events.jsonl:167` 的首个 5 s 后 drain 观测窗口：最老 pending 年龄最大值为 **200.042349999 ms**，超过既定 **200 ms** 截止。其 5 个状态、4 个完整间隔均有积分进展和计数守恒，overflow 无增长；其中单个间隔 expired 增加 2，未构成连续两个间隔的过期增长。不能把这个 unknown 改成已证实“持续积压”，也不能因为超限很小而在结果生成后放宽门槛。

`straight_02` 的误差比为 `0.14266594642012756 / 0.11352257254374161`。实际 CPP 首次 sample 的 y 为 −9.9997124877，首条路径在 y=−9.75；Python 首次 sample 的 y 为 −10.0002704955，首条路径主要在 y=−10.25，末段转至 −9.75 并连接精确目标。约 0.558 mm 的起点差跨过了网格边界，构成离散选格与终点语义的混杂证据；这里仍按原协议保留相对失败。只有独立格内复验才能评价消除该混杂后的表现。
