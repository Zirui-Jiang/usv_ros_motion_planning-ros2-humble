# 软膨胀区驶出修复后的独立复验协议

本协议在新的完整矩阵执行前固定。它沿用格内场景几何与全部验收门槛，明确改变
Python 版本和导航配置；不覆盖 `python-grid-interior-001` 或两个已中断候选。

| 项目 | 固定对象 |
| --- | --- |
| Python 数值及验收版本 | `e38183218fce7044e686a0f697ed13f456f49039` |
| C++ 对照版本 | `632734ba31478bdb833e15949287b53ae9334cf3` |
| 场景文件 | `scripts/validation/scenarios_grid_interior.json` |
| 场景 SHA256 | `13f08a3d6e5d6712f616c3e6e2214d819bca5305c3177579439a5143eb805f18` |
| Python / C++ 障碍因子 | 0.25 / 0.5；阈值公式均为 `254 * factor` |
| Python PID | 原增益与分配、2.6 s 预瞄 |
| Python LQR | 原 A/B 与 Riccati 方程、2 s 预瞄、Q=[1,1,100,10,10,10]、R=[20,20] |
| Python LOS | 前视 1 m、切换距离 5 m、每输出区间最多推进一个航点 |
| 候选准入 | `c0139be` PID 圆柱三次均通过，间隙 0.747–0.829 m；`e381832` 仅补齐已有逃逸规则的路线复用一致性，新增六项回归，全仓 368 项通过 |
| 完整矩阵 | PID/LQR × 直航/转弯/圆柱 × 三次，另测目标更换、取消、独立里程计断流 |

恢复软区驶出不改变搜索边代价和邻域；仅初始高软代价前缀可以逐格严格下降，
不能借此穿越硬障碍或默认未知区域。路径段检查与重采样使用同一约束。
这项恢复修复了 Python 严格起点拒绝引入的停车回归。较宽全局路线属于配置校准，
不能说成与旧版本参数完全相同，也不能据此证明未来惯性扫掠安全。

完整矩阵使用独立结果目录、运行前后源码与安装指纹、实际参数读回。每次重新启动、
复位、预检并发布目标，运行中不调参。若触发负的保守扫掠下界或固定横偏超过 4 m，
验收脚本自动结束当前采集、关闭其自有 launch 并停止矩阵，其余项目标记为未运行。
正间隙低于 0.2 m 仍为验收失败，不以较细离线复核回写原结果。

比较只使用 `baseline-grid-interior-001` 的对应场景、重复编号。该基线 PID 九次完成、
七次通过；圆柱第二、三次裕度失败，所以不能作为双方通过的比例分母。LQR 缺少
该协议有效完成的 C++ 基线，应标不可比。原协议的基线和失败不得混入这组配对。
有效配对的 RMSE 与到达时间门槛仍为 Python/C++ ≤1.10，缺失值不补零。

控制 P99 <100 ms，扫描处理 P95 不超过同窗扫描周期；0.2 s 队列准入、积压、
字段完整性与过期/溢出规则保持不变。新版本计数器增加 `invalid_consumed`，比较器
按明确的新旧 schema 校验守恒，不因为字段变化放宽性能门槛。1 Hz OS 采样按其真实
覆盖区间单独报告，不把进程资源等同于整机资源或瞬时峰值。

本文件固定完整矩阵开始前的准入证据和规则，不表示完整矩阵已经通过。实际状态统一写入结果归档和
[验收报告](../python-migration-validation.md)。
